# CryptoAI PRO — Android APK

The sideloadable app is in this folder: **`release/CryptoAI-PRO-1.0.0.apk`**

1. Send the APK to your phone.
2. Tap it → allow "install unknown apps" when Android asks → Install.
3. Open **CryptoAI PRO** (gold icon).

Android 7.0+ · ~130 KB · signed (v1/v2/v3) · package `com.cryptoai.pro`
