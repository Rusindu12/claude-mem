# Experimental model

This small MLP predicts whether the next hourly close is higher from the previous eight log returns. It is a research demo, **not an automated trading model**. An optional paper-only bot uses it with an illustrative 0.5 threshold. The rule-based indicators do not use it. Do not trade on its outputs.

Training data: BTCUSDT, ETHUSDT and SOLUSDT 15-minute spot candles from https://github.com/AdidyaAbimanyu/dataset, aggregated into complete hourly candles. The model file records each source file's SHA-256 and sample time range. This is only about 30 days of data; it is not representative of different regimes and is not futures data. Splits are chronological for each pair, 70/15/15, with boundary samples removed to prevent labels crossing splits. The pooled held-out test accuracy was 52.96%, below the 57.01% majority-class baseline; validation accuracy was 46.86% vs 52.52%. An illustrative long/flat held-out close-to-close simulation using a 0.5 threshold and an assumed 0.1% fee per turnover produced BTC -2.88%, ETH -5.64%, SOL -3.34% over 107 hourly predictions each. It assumes ideal fills at the signal close and excludes slippage, latency and spreads. It is not the paper bot strategy (which has TP/SL and may allow shorts), and is not evidence of profitability or real-world validation.

To reproduce: install Python, numpy, pandas and scikit-learn; clone the dataset repository, then run `python model/train.py /path/to/dataset --output app/src/main/assets/model.js` from the Android project folder. Package versions used: see `requirements.txt`. Source data is not redistributed here.
